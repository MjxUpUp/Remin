# ADR-0002 内嵌确定性 BM25，不引入向量库

- 状态：accepted（2026-09-21）

## 背景

P2-H6 要求确定性检索（同索引版本 + 同查询 → 同结果），禁用模型端随机 rerank 作为主路径。调研结论（会话 sess_e00fb2a4）：BM25 实测与 embeddings 检索质量打平，成本约 1/100；嵌入索引仅允许作为可重建加速层。

## 决策

`internal/search` 内嵌自研 BM25：固定分词（小写化 + 非字母数字切分 + CJK 二元组）、固定参数（k1=1.2, b=0.75）、按 id 稳定排序。索引为版本化派生物（`index/bm25-<ver>.json`），可由真源全量重建，不入 git。不引入任何向量库/嵌入依赖。

## 后果

- 正：零外部服务、毫秒级 JIT、确定性可测试、无模型绑定（P4-R1）
- 负：语义近似弱于嵌入（由弃权机制兜底：宁可不知道）；中文需显式二元组分词（已实现）
- 阈值：最高分 < 0.05（固定常量，不可配——确定性要求运行时零可调参数）判为置信不足 → abstain；无命中必 abstain
